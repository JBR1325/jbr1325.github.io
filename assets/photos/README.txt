BRINDI'S BISTRO — PHOTO DROP-IN FOLDER
======================================

The website shows elegant styled placeholders wherever a real photo can go.
To replace a placeholder with a real photo, just drop an image file into THIS
folder using the exact filename listed below. No code changes needed — refresh
the page and the real photo appears automatically. (If a file is missing, the
styled placeholder stays.)

Recommended format: .jpg (or .webp). Keep files reasonably web-sized (long edge
~1600px, under ~400KB each). Crop to the aspect ratio noted so nothing looks
stretched.
